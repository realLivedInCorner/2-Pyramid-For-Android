## 2. Conversion risk is yours

Resource-pack version conversion involves a large amount of heuristic processing of textures, models,
shaders and UI. There is **no guarantee** that any given pack converts correctly for every target version.
Possible outcomes include:

- misaligned textures, color drift, or broken UI;
- shaders failing on the target version or crashing the client;
- an output pack structure you did not expect;
- **Java ↔ Bedrock conversion is experimental**: incomplete and known to be broken (selecting that target
  shows a warning). **Do not use its output for public releases or production**; it is for testing only;
- **OptiFine CIT conversion is off by default**: users reported purple/black bow and diamond-sword models
  after a 1.20.1 → 1.21.9–1.21.10 conversion. The offline codec review fixed a definite format error, but
  in-game rendering has **not** been verified; CIT definitions are therefore not generated by default.
  Enable it explicitly in the conversion options and verify in-game first.

**Back up your original packs and verify results in a test environment before using them seriously.** The
authors are not responsible for file corruption, data loss, broken game saves or other damage caused by
using this software.
